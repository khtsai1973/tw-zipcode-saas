# 門牌整編／舊址對照（address_remap.json）

台灣「門牌重新編排」由各縣市戶政公告，**沒有單一全國開放總表**。  
本服務採三層處理：

1. **行政區改制**（內建）：舊鄉鎮市／縣名 → 新直轄市區（如板橋市→新北市板橋區）
2. **中華郵政改正**：官方 WS 若回傳不同地址字串，標記「舊址已改正」並採用新址
3. **自訂對照表**：把確定的「舊地址 → 新地址」寫入本檔，查詢前優先套用

## 格式

```json
[
  {
    "old": "舊完整地址",
    "new": "新完整地址",
    "note": "門牌整編民國xxx年（選填）"
  }
]
```

- `old` 與 `new` 必須不同才會生效
- 建議填入正規化後的完整地址（縣市+行政區+路+號）
- 修改後需重新部署／重啟服務（表會快取）

資料來源參考：各縣市戶政「門牌整編專區」、內政部戶政司村里街路門牌查詢。
